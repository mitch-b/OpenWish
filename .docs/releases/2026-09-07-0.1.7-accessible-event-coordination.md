# OpenWish 0.1.7 - 2026-09-07

## Accessible event coordination

Event invitation status filters now communicate their selected state and the
number of matching invitations. Invitation dialogs identify their purpose,
consequence, tabs, and friend search field for keyboard and screen-reader
users.

An invitee can now identify the confirmation controls before declining an
event. Event wishlist attachment and removal controls connect visible labels
and destructive consequences. Gift-exchange pairing-rule selectors also retain
their visible labels.
