# OpenWish 0.1.11

Creating wishlists and gift ideas now provides dependable progress and failure
feedback, while confirmation dialogs and privacy choices work more predictably
from a keyboard.

## Improved

- Confirmation dialogs contain keyboard focus, close with Escape, and return
  focus to the action that opened them.
- Wishlist visibility choices use native radio controls while preserving the
  existing clear descriptions.
- Wishlist creation prevents duplicate submissions and keeps an actionable
  error on the form when creation fails.
- Standalone item creation prevents duplicate submissions and keeps an
  actionable error on the form when creation fails.
- Secret Santa assignment failures now explain what happened and provide a
  retry action instead of looking like no assignment exists.
