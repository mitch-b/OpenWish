# Install OpenWish - November 21, 2026

- Add OpenWish to your Home Screen with the updated ribbon icon. Supported
  mobile browsers offer installation in OpenWish; Safari shows the Home Screen
  steps instead.
- Choose **Not now** to stop seeing the reminder in that browser. You can still
  install at any time from **Account settings > Install as app**.
- If your browser saves a shortcut instead of installing the app, add it from
  the OpenWish homepage to get the OpenWish name and ribbon icon. OpenWish
  now also provides the ribbon icon as a multi-size favicon for browser
  shortcuts. Firefox on Android may add a Firefox badge. If an old shortcut
  keeps its previous icon, remove the shortcut and add it again after updating
  OpenWish. Use HTTPS when installing from another device.
- Installation does not store private wishlists, gift exchanges, or other
  account data for offline use.
