# OpenWish 0.1.14

OpenWish now keeps event coordination dependable when network or session
problems interrupt invitations, pairing rules, name drawing, or deletion.

## Improved

- Event deletion failures stay in the confirmation dialog with a clear retry.
- Pairing-rule loading failures no longer look like an empty rule list.
- Pairing-rule changes prevent repeated requests and announce their outcome.
- Drawing names and resetting a gift exchange show actionable errors without
  exposing internal failure details.
- Invitation lists, friend choices, and invitation actions provide retry,
  progress, success, and failure feedback.
