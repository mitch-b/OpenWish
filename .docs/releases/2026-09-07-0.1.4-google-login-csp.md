# OpenWish 0.1.4 - 2026-09-07

## Google sign-in handoff

Google sign-in now permits the browser to follow the authentication redirect to
Google. Previously, the browser's Content Security Policy blocked the handoff
even when the local sign-in endpoint and form submission were correct.

Only Google's HTTPS authorization origin is added to the form destination
policy, and only when Google sign-in is configured. Other browser policy
restrictions remain unchanged.

Browser regression coverage now follows the real challenge redirect on desktop
and mobile, checks the callback URL, and rejects browser errors. Google's
authorization response is intercepted so no real account or external service
is needed.
