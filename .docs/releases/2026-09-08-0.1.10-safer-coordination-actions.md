# OpenWish 0.1.10

Event navigation and gift-coordination actions now provide clearer keyboard
behavior, safer choices, and dependable feedback.

## Improved

- Event cards use an explicit, named link instead of pointer-only navigation.
- Reserved-item refreshes announce progress and results, while errors, counts,
  and new-tab destinations provide clearer context.
- Friend-request actions name the person involved, prevent duplicate updates,
  and announce success or failure.
- Comment deletion requires a focused confirmation, explains permanence, and
  communicates progress and completion.
- Reservation cancellation requires a focused confirmation, explains when the
  item becomes available again, and communicates completion.
