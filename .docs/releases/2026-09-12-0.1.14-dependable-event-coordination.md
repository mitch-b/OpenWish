# OpenWish 0.1.14

OpenWish now keeps event coordination dependable when network or session
problems interrupt invitations, pairing rules, name drawing, or deletion.

## Improved

- Event deletion failures are checked before retry so a completed deletion is
  never repeated.
- Pairing-rule loading failures no longer look like an empty rule list.
- Pairing-rule changes are idempotent, reconcile interrupted responses, and
  announce their outcome.
- Drawing names and resetting a gift exchange reconcile interrupted responses
  before offering another action, without exposing internal failure details.
- Invitation lists, friend choices, and invitation actions provide retry,
  progress, success, and failure feedback.
