# OpenWish 0.1.6 - 2026-09-07

## Clearer gift coordination controls

Wishlist tabs now identify their active content, and the search, visibility,
and sort controls keep visible labels. Search and filters announce the number
of matching wishlists.

Reservation and comment controls now communicate whether their details are
open. Event deletion confirmation is announced as a destructive dialog and
describes the permanent effect before an organizer proceeds.
