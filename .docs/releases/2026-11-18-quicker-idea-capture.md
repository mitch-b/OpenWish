# Quicker idea capture - November 18, 2026

Journey J2, "Capture and curate": adding several ideas takes fewer steps and
catches repeats.

- **Add another from the add page.** The full-page "Add an item" form now has
  "Add and add another", matching the dialog on a wishlist. It confirms each
  idea and returns focus to the link field.
- **Added confirmation.** After "Add item" on that page, the wishlist shows
  "<name> was added to your list." The message is looked up from the list by
  the idea's public ID, never read from the address.
- **Store from the link.** Typing a product link fills an empty "Where to buy"
  with the store name when you leave the field. Anything you typed is kept.
- **Repeat heads-up.** If the list already has an idea with the same name or
  product link, a note says so. You can still add it.
- **Consistent clear.** The Friends' wishlists search clear button reads
  "Clear", like the one on My wishlists.

No schema changes. Ideas are only compared with the list you are adding to.
