# From your friends to their wishlists - November 1, 2026

Moving between people and their lists takes one step.

- Each friend has a "View lists" action that opens only that friend's shared
  wishlists. Accepting a friend request offers the same link.
- Friends' Wishlists can be searched by list or friend name, with a clear way
  back to everyone.
- Friend invitations check the email addresses first, name any that look
  wrong, ignore duplicates, and send with Ctrl+Enter.
- Friends are sorted by name with a count, and accepting, removing, or
  requesting friends updates the page in place without flashing a spinner.

Only lists a friend already shares with you appear; nothing new is exposed.
