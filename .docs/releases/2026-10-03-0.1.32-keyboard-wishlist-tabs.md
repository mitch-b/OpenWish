# Easier keyboard wishlist browsing - October 3, 2026

The wishlist tabs now work as a keyboard tab set. Use the left and right arrow
keys to move between your wishlists and friends' shared lists, or Home and End
to jump to either end. Focus follows the selected tab, and Tab moves into its
panel instead of stopping on a hidden choice.

Accessibility markup tests and the isolated browser journey cover focus,
selection, loaded wishlist content, authenticated API responses, and desktop
and mobile screenshots.
