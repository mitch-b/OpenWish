# More dependable friend invitations - September 27, 2026

Five small improvements make it easier to connect with the right person:

1. Requests to your own account are rejected without creating a self-friendship.
2. Requests to unknown accounts return a clear not-found response.
3. Inviting an existing account by email works even when the capitalization differs; the person receives a friend request rather than a registration invitation.
4. Sending another invitation with different email capitalization reuses the pending invite rather than creating a duplicate.
5. If two people become friends before a pending invitation is accepted, accepting it clears the stale invitation.

Automated service tests cover these boundaries, and the isolated browser journey checks that inviting an existing account by mixed-case email creates a sent request.
