# OpenWish 0.1.8

Wishlist browsing and item capture now provide clearer context for keyboard and
screen-reader users.

## Improved

- Item search has a visible programmatic label, a named clear action, and a
  polite update with the number of matching ideas.
- The filter control identifies its expanded panel, while priority, status,
  and price controls expose their purpose and current state.
- Sorting choices communicate which order is active.
- Grid and list controls communicate the selected wishlist view.
- Product URL import fields connect their labels and guidance, prevent empty
  imports, and sit inside a named add-item dialog that contains and restores
  keyboard focus.
