# OpenWish 0.1.5 - 2026-09-07

## Reliable release versioning

OpenWish now keeps the version embedded in its compiled assemblies aligned with
the current release version shown to operators and users. This makes deployed
builds easier to identify accurately when reviewing logs, diagnostics, and
package metadata.

Automated coverage verifies that the release version, build metadata, and
latest "What's new" entry remain synchronized.
