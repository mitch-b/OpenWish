# More dependable friend invitations - October 5, 2026

If an invitation email cannot be delivered, it no longer appears in the pending
list as though it was sent. Failed resends keep their previous sent date, and
bulk invitations report delivery outages instead of masking them as partial
success. Operators should check their email configuration when delivery fails.

When a recipient registers after receiving an invitation, inviting them again
now sends a friend request and closes the obsolete registration invitation.
Accepting a registration invitation saves the friendship before notifying the
inviter, preventing a notification failure from announcing a friendship that
has not been recorded.

Focused service regressions cover all five outcomes. The isolated browser
journey checks authenticated existing-account invitations, populated friend
views, desktop and mobile screenshots, browser responses, and application logs.
