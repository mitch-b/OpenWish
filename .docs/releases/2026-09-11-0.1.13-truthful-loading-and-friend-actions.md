# OpenWish 0.1.13

OpenWish now gives clearer feedback while wishlists, friends, and personalized
dashboard details are loading or unavailable.

## Improved

- Personal wishlist failures no longer look like an empty collection.
- Friends' wishlist failures no longer look like nobody has shared a list.
- Friend invitations prevent repeated sends and communicate progress and
  failures.
- Friend lists offer a retry when loading fails, and removals use named actions,
  explain the sharing consequence, and announce completion.
- The dashboard reports when personalized content is still loading.
