# Find and connect integrations - November 7, 2026

The Integrations page is now reachable from the main navigation and account
settings, even when no apps are registered. It explains how to build a
server-side app, links to the integration guide and public `llms.txt`, and
shows whether this OpenWish has enabled its optional MCP server.

When MCP is enabled, people can copy its address and connect through a browser
sign-in and consent flow, then choose which lists the assistant may use. No
password or bearer token needs to be copied into an assistant.
