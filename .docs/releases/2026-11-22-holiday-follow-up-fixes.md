# Holiday follow-up fixes - November 22, 2026

Fixes from an independent review of the holiday polish release.

- **Private lists stay private.** A private wishlist attached to an event is no
  longer visible to event members who open its link. The event page, the list's
  settings, and its privacy label now agree.
- **Commenters' emails stay private.** Wishlist pages no longer send comment
  authors' email addresses to the browser.
- **Comment counts keep up.** Adding or deleting a comment updates the comment
  count, item badges, and the "Has comments" filter right away.
- **Notifications on tablets.** The notifications panel fits beside the sidebar
  instead of sliding under it.
- **Two-factor settings.** Opening the replace recovery codes or turn off
  two-factor pages while two-factor authentication is off returns you to its
  settings with a message instead of an error page.

No schema changes.
