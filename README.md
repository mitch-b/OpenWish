# <img src="src/OpenWish.Web/wwwroot/images/openwish-color.svg" alt="OpenWish logo" height="42" style="vertical-align: middle;"> OpenWish

**Thoughtful gift giving, without duplicate purchases or spoiled surprises.**

OpenWish is a self-hosted home for the wishlists, private gift coordination,
and name draws that make a small group's celebrations feel easy. Keep the
planning with the people you trust—not a marketplace, ad network, or public
profile.

## What makes OpenWish different

**Surprises stay surprises**

- Reservations and purchases are never shown to the person receiving the
  gift. Shoppers can also reserve anonymously, hiding their name from other
  shoppers. Item comments are visible to everyone who can see the item,
  including the list owner.
- A private gift history gently warns you before you give someone the same
  gift twice.
- Viewer-specific privacy protects private lists, sharing choices, and
  name-draw assignments. Connected apps never see reservations, purchases, or
  comments.

**Gift exchanges that run themselves**

- Create an event for a holiday, birthday, or team tradition, with a date,
  budget, and an organizer checklist that always shows the next step.
- Invite friends, whole circles, or any email address. Invitees can join with
  an account or as a guest with no account at all.
- Draw names privately with optional pairing rules, such as keeping partners
  from drawing each other. Each person unwraps only their own match.
- After the occasion, reveal who drew whom to the group, then "Run it again"
  next year without repeating last year's pairings when possible.
- Add events to your calendar and get branded invitation, draw, and reminder
  emails when SMTP is configured.

**Wishlists that are faster than a notes app**

- Paste a product link from almost any store: OpenWish fills in the name,
  price, image, and store. Add ideas from your phone's share sheet when
  installed, from a bookmarklet, or by typing a quick note.
- Rank ideas, mark what is most wanted, set priorities, and organize many
  ideas at once: move, copy, archive, or mark them received.
- Share a list privately, with every friend, with chosen friends or circles,
  or with an event. Collaborative lists let others add ideas too.
- Gift hints share sizes, favorites, and things to avoid. Shoppers can filter
  a list by their exchange budget.
- Copy a list as text, print it, or download it as CSV. Export and import
  every list you own as JSON.

**Shopping that stays organized**

- "My gift plan" gathers everything you reserved by person and occasion, with
  budgets, over-budget flags, bought and wrapped progress, and a copyable
  shopping list.
- The dashboard surfaces what needs you now: invitations, friend requests,
  gifts still to buy, names to draw, and upcoming birthdays, which you can
  download to your calendar.

**Friends, not followers**

- Connect by request, email invitation, or in person with a short-lived code
  and QR code. Suggestions come only from people you already share with.
- Group friends into circles, like Family or Book club, to share lists or
  invite people to events in one step.
- In-app notifications let you mark each one read only when you are done.

**Connected apps and AI assistants**

- Let apps you trust add, update, and remove ideas on only the lists you
  choose, labeled with where each idea came from.
- Operators can turn on an MCP server so people can ask an AI assistant such
  as Claude, ChatGPT, or Copilot to save gift ideas. See
  [connected apps](.docs/INTEGRATIONS.md).

**Yours to run**

- Install it as an app on phones and computers, with an offline page, light
  and dark themes, and a layout checked at phone, tablet, and desktop widths.
- Self-host the published Docker image with your own PostgreSQL database.
  Sign in with a password, optional Google sign-in, and two-factor
  authentication.
- "What's new" in the app explains each release in plain language.

## Built with dependable, portable tools

OpenWish is an ASP.NET Core [.NET 11](https://dot.net/) application with Blazor
server rendering and interactive WebAssembly, PostgreSQL via Entity Framework
Core, and published Docker images. It is designed to be understandable to the
person who runs it as well as useful to the people who use it.

Docker images are [published on GitHub](https://github.com/mitch-b/OpenWish/pkgs/container/openwish-web).

## Installation

### Docker Compose

Since OpenWish depends on an external datasource (PostgreSQL), if you don't already have a PostgreSQL instance to use, you can run an instance alongside the OpenWish application using Docker Compose:

```yaml
services:
  sql:
    image: postgres:18
    container_name: openwish-postgres
    environment:
      POSTGRES_USER: "openwish"
      POSTGRES_PASSWORD: "YourStrong!Passw0rd"
      POSTGRES_DB: "OpenWish"
    volumes:
      - openwish-data:/var/lib/postgresql
    ports:
      - 5432:5432

  web:
    image: ghcr.io/mitch-b/openwish-web:latest
    container_name: openwish-web
    environment:
      - TZ=America/Chicago
      - ConnectionStrings__OpenWish=Server=sql;Port=5432;Database=OpenWish;User Id=openwish;Password=YourStrong!Passw0rd;
      - OpenWishSettings__OwnDatabaseUpgrades=true
    ports:
      - 5001:8080
    depends_on:
      - sql

volumes:
  openwish-data:
```

See [package versions](https://github.com/mitch-b/OpenWish/pkgs/container/openwish-web/versions) for published tags. Use `{year}{month}` tags (for example, `202601`) to manage upgrades.
