# More reliable product link imports - October 3, 2026

Adding a gift idea from a product link now picks up page metadata and image
links more reliably. If a shop redirects the link, relative image paths use
the final product page address, so the suggested image points to the right
place. Unsafe image addresses remain excluded.

Focused scraper tests cover redirected product pages with image tags and
Open Graph metadata. The isolated browser journey covers authenticated product
import safeguards, populated wishlist views, clean browser and server logs,
and desktop and mobile screenshots.
