# Cleaner gift coordination history - October 4, 2026

Inviting a friend by email now accepts accidental spaces around the address
without passing them into the invitation or registration link. An invitation
that has already been accepted or cancelled can no longer be cancelled again.

Your activity history no longer shows earlier changes to removed wishlists or
gift ideas. It still records when you removed them, so the history remains
understandable. When a product page supplies a malformed or unsafe image link,
the available name, description, and price can still be imported.

Focused service tests cover these five outcomes. The isolated browser journey
checks authenticated activity after deleting a synthetic gift idea, populated
pages, desktop and mobile screenshots, browser responses, and application logs.
