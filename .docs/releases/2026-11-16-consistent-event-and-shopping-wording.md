# Calmer event and shopping screens - November 16, 2026

Five small polish fixes found while walking the gift-exchange participant and
shopper journeys (J6).

- **Compact gift plan summary on phones.** The four summary figures sit in two
  columns instead of one tall stack, so the first gifts appear sooner.
- **One wording for budgets.** An event or match without a budget now says
  "No budget set" instead of "Not set".
- **Sentence-case headings.** "My reserved items" on an event matches the rest
  of the page.
- **Clearer share button.** The wishlist beside "Share wishlist" on an event
  now reads "Not shared yet: <name>", so it is clear what the button shares.
- **Consistent wishlist tabs.** "My wishlists" and "Friends' wishlists" use the
  same capitalization as the navigation and headings.

No privacy or data changes.
